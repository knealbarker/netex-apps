# netex-apps

Apps and shared data for Town & Country Cleaners (netexcleaners.com).

- **Start here:** `CLAUDE.md` (overview and rules), `docs/platform.md` (how netexcleaners.com is set up),
  `docs/new-app.md` (adding a subdomain app), `docs/business-rules.md` (definitions).
- **Starter for a new app:** `workers/_template` (sign-in, roles, Users & access, example data, tests).
- Apps: `workers/planner`, `workers/retail`, `workers/sync`, `workers/auth`, `workers/mcp`. Database: `db/`.
